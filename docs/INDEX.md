# Ports Documentation Index

This directory documents recipes and patches for integrating external software into Wicofe.

## Scope
- Reproducible upstream build recipes.
- Wicofe-specific patches and patch rationale.
- Upstream version/commit tracking.
- Dependency metadata, build instructions, and port status.
- License, provenance, and security review records.

## Ownership
[WPM](https://github.com/Waizusora/WPM) owns package installation and repository operations. [Wicofe-Build](https://github.com/Waizusora/Wicofe-Build) owns whole-system build orchestration. [Wicofe-ThirdParty](https://github.com/Waizusora/Wicofe-ThirdParty) owns third-party provenance/license inventory. Ports must link to the corresponding component records rather than duplicating the compliance source of truth.

## Porting policy
Prefer minimal, reviewable, upstreamable patches. Record exact source versions, checksums, licenses, enabled features, and patch origins. Do not redistribute code without checking its terms.
